# 系统测试说明

## 1. 自动化验证

后端使用 JUnit 5、Spring Boot Test 和 H2 内存数据库，覆盖 JWT 签发解析、数据库用户角色映射、工单状态机、需求地址归属、评价重复提交、投诉状态、接口登录响应和 MyBatis 映射。运行 `cd backend && mvn test`。

前端使用 Vite 生产构建验证依赖、Vue 模板、Element Plus 组件和 ECharts 引入，运行 `cd frontend && npm run build`。

## 2. 核心测试用例

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T01 | 正确账号密码登录 | 返回 200、JWT 和角色 |
| T02 | 错误密码登录 | 返回认证失败，不签发令牌 |
| T03 | 客户使用其他客户地址提交需求 | 返回业务错误 |
| T04 | 工单从待审核直接跳到服务中 | 状态机拒绝 |
| T05 | 服务人员拒绝本人待接单工单 | 回到待分配并写入历史 |
| T06 | 同一人员同一时间重复派单 | 返回时间冲突 |
| T07 | 服务人员操作未分配工单 | 返回越权错误 |
| T08 | 客户重复评价同一工单 | 返回已评价错误 |
| T09 | 没有统计数据 | 返回零值和空数组，页面显示暂无数据 |

## 3. 人工验收流程

导入演示数据后按“注册/登录—需求—审核—派单—接单—开始—完成—验收—评价—投诉—统计”顺序验证，并检查工单状态历史、调度记录、过程记录和投诉处理记录是否关联到同一工单。

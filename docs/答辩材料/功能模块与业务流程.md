# 功能模块与业务流程说明

## 功能模块

用户权限 → 服务分类/项目/区域 → 客户地址与需求 → 工单审核与状态 → 人员调度 → 服务过程与图片 → 验收评价 → 投诉返工 → 质量统计 → 公告和日志。

## 一次服务的业务流

1. 客户登录并选择启用的服务项目。
2. 客户提交属于自己的地址和预约时间，需求进入待审核。
3. 管理员审核需求，在事务中生成待分配工单。
4. 系统按规则返回候选服务人员，管理员派单并保存原因。
5. 服务人员接单，记录开始、服务中和完成过程。
6. 客户验收，工单进入已完成后提交评价。
7. 客户如有问题提交关联工单的投诉，管理员处理并记录结果。
8. 统计接口汇总状态、趋势、完成数、评分和投诉数据。

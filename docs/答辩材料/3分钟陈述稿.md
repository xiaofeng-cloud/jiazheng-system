# 3 分钟开题陈述稿

各位老师好，我的毕业设计题目是《基于 SpringBoot 与 Vue3 的家政服务工单调度与服务质量追踪管理系统设计与实现》。本课题面向中国大陆家政服务企业，重点解决需求信息分散、人工派单难以解释、服务过程缺少记录和投诉评价无法闭环的问题。

系统包括客户、家政服务人员和系统管理员三类角色。客户可以浏览服务项目、维护地址、提交需求、查看工单、验收评价和投诉；服务人员可以查看本人派单、接单或拒单、记录签到和服务过程、上传前后图片标识；管理员负责需求审核、人员调度、质量监督、公告、日志和统计。系统以“需求提交、审核、派单、接单、服务、验收、评价、投诉、统计”为主流程。

技术上采用 Vue3、Element Plus、Pinia、Axios 和 ECharts 构建前端，SpringBoot、Spring Security、JWT、Hibernate Validator 和 MyBatis-Plus 构建后端，MySQL 8.0 负责数据存储。工单状态由后端状态机统一管理，调度依据技能、区域、时间冲突和工作负载给出可解释结果，关键操作写入历史记录。

本课题的重点是角色数据范围、工单状态一致性和质量追踪。预期完成可运行的前后端系统、数据库脚本、初始化数据、测试和中文项目文档。系统只用于家政服务工单和质量管理，明确排除微信小程序、在线支付、充值、退款、押金、交易和结算等功能。我的陈述完毕，谢谢各位老师。

# 开发进度计划

| 阶段 | 主要工作 | 产出 |
| --- | --- | --- |
| 第 1 周 | 需求分析、角色和架构确定 | 需求分析、架构设计 |
| 第 2 周 | MySQL 表结构、外键、索引和演示数据 | 建表、种子、校验脚本 |
| 第 3 周 | Spring Security、JWT、用户和权限 | 登录注册、统一响应 |
| 第 4 周 | 服务项目、区域、地址、需求和工单 | 基础资料与状态机接口 |
| 第 5 周 | 调度规则、接单、服务过程和图片 | 调度与时间线接口 |
| 第 6 周 | 验收评价、投诉处理和统计 | 质量闭环与看板接口 |
| 第 7 周 | Vue3 页面和真实接口联调 | 登录、工作台、工单页面 |
| 第 8 周 | 测试、文档、答辩材料和仓库整理 | 测试报告、演示和提交 |

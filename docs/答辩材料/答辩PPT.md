# 答辩 PPT（约 10 页）

## 第 1 页：题目与基本信息

题目、学生、专业、指导教师、日期（均按学校模板填写）。

## 第 2 页：研究背景

家政服务需求、派单、服务过程和售后信息分散，人工协同难以追踪；系统的目标是形成一条可查询、可审计的服务链路。

## 第 3 页：需求与角色

展示客户、服务人员、管理员三类角色及权限边界，强调纯 Web 前后端分离。

## 第 4 页：总体架构

展示 Vue3 + Element Plus + ECharts、SpringBoot + Security + JWT、MySQL + MyBatis-Plus 的分层关系。

## 第 5 页：功能模块

用户权限、服务基础、需求工单、人员调度、服务过程、质量闭环、统计日志七组模块。

## 第 6 页：业务流程

需求提交 → 审核 → 生成工单 → 调度 → 接单 → 服务记录 → 完成 → 客户验收 → 评价/投诉 → 统计。

## 第 7 页：数据库设计

展示用户、需求、工单、调度、过程、评价和投诉的 ER 关系，说明外键和状态历史。

## 第 8 页：关键设计

说明状态机、调度规则、JWT 认证、角色数据范围、操作日志和事务边界。

## 第 9 页：系统演示与测试

展示登录、工作台、工单筛选、趋势图和质量数据，汇报后端测试、映射冒烟测试和前端构建结果。

## 第 10 页：总结与展望

总结当前成果，展望更多真实页面、文件存储和部署优化；明确本课题不涉及支付或资金功能。

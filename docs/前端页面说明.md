# 前端页面说明

当前前端入口 `frontend/src/App.vue` 提供登录页、侧边菜单、工作台和工单列表。登录后根据角色显示角色标识，工作台通过 `/api/statistics/dashboard` 获取统计数据，工单列表通过 `/api/work-orders` 获取当前用户可见数据，页面在无数据库时显示空数据提示。

| 页面 | 主要内容 | 对接接口 |
| --- | --- | --- |
| 登录页 | 账号密码、错误提示、演示账号提示 | `/auth/login` |
| 工作台 | 完成数、待分配、服务中、平均评分、趋势图、待办 | `/statistics/dashboard` |
| 工单管理 | 状态筛选、编号、项目、客户、服务人员和日期 | `/work-orders` |
| 服务人员、质量监督、统计分析 | 菜单入口和模块占位 | 后续页面迭代 |

`src/api/http.js` 统一注入 JWT，`src/stores/auth.js` 负责令牌持久化和退出。前端只做交互和展示，角色权限仍由后端校验。

# 后端接口说明（当前阶段）

后端统一使用 `/api` 前缀，登录后在请求头携带 `Authorization: Bearer <token>`。

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/login` | 用户名密码登录，返回 JWT 和角色 |
| GET | `/api/auth/me` | 获取当前登录账号 |
| PUT | `/api/work-orders/{orderId}/status` | 按状态机变更工单状态并写入历史 |

演示账号：`admin`、`customer01`、`provider01`，密码均为 `123456`。工单状态请求体示例：

```json
{"status":"IN_SERVICE","remark":"服务人员已开始服务"}
```

接口层只负责接收请求，状态合法性由 `WorkOrderStatusService` 统一校验，数据层使用 MyBatis-Plus/MyBatis 注解访问 `work_order` 和 `work_order_status_log`。

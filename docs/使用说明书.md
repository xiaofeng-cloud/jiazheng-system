# 系统使用说明书

## 登录

打开前端地址，输入演示账号和密码。管理员进入工作台后可查看统计和工单；客户可以维护地址和提交需求；服务人员可以查看派单并记录服务过程。

## 一次服务流程

客户选择启用的服务项目并填写本人地址和预约时间，提交后状态为待审核。管理员审核后生成待分配工单，在调度页面查看候选人员并派单。服务人员接单、记录开始和完成过程，客户在待确认状态验收并评价。出现服务问题时，客户从原工单提交投诉，管理员处理并填写结果。

## 常见问题

- 登录失败：确认数据库已经导入并检查 `application-local.yml` 的连接信息。
- 看板暂无数据：确认后端已连接数据库，接口返回空数组时页面会显示空数据提示。
- 工单不能跳状态：必须按状态机顺序执行，检查当前状态和当前角色权限。

本系统只用于服务工单和质量管理，不包含任何支付、充值、退款、押金或结算操作。

# 环境部署说明

## 1. 软件要求

JDK 17 或更高版本、Maven 3.9 或更高版本、Node.js 20 或更高版本、MySQL 8.0。Windows、Linux 和 macOS 均可按相同目录结构部署。

## 2. 数据库

创建数据库和演示数据：

```bash
mysql -u root -p < database/01_schema.sql
mysql -u root -p < database/02_seed_data.sql
```

首次导入会重建本项目表，请确认目标数据库为开发数据库。导入后可用 `admin`、`customer01`、`provider01` 登录，密码均为 `123456`。

## 3. 后端

复制 `backend/src/main/resources/application-local.yml.example` 为同目录的 `application-local.yml`，填写本机 MySQL 密码和至少 32 位 JWT 密钥。然后运行：

```bash
cd backend
mvn test
mvn spring-boot:run
```

后端端口为 8080，接口文档路径为 `/swagger-ui.html`（接入 Knife4j 后可在此基础上扩展）。

## 4. 前端

```bash
cd frontend
npm install
npm run dev
```

Vite 默认端口 5173，`vite.config.js` 将 `/api` 转发到 `http://localhost:8080`。生产构建使用 `npm run build`，生成 `frontend/dist`。
